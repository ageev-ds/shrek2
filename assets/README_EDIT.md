# Как менять игру «Путь Шрека»

Всё, что видно в игре, лежит в этой папке. Пересобирать программу не нужно: поменяли файл → перезапустили игру (или нажали «⟳ Перечитать файлы» в режиме редактирования).

Проще всего править через саму игру: **главное меню → «✏ Режим редактирования»** (или `Ctrl+Shift+E`). Там есть вкладки «Команды», «Локации», «Вопросы и задания», «Настройки и тайминги». Кнопка «💾 Сохранить» записывает изменения в файлы из `config/`. Перед первым сохранением за запуск создаётся резервная копия `config/*.bak.json`.

## Папки

| Папка | Что там |
|---|---|
| `config/` | Тексты, вопросы, команды, локации, очки, тайминги (JSON) |
| `images/characters/` | Картинки персонажей: фишки команд и картинки для «Найди лишнее» |
| `images/map/` | Фон карты (`background.svg`) и иконки 9 локаций |
| `images/ui/` | Любые свои картинки |
| `videos/` | Ролики. Все необязательные: если файла нет, ролик просто пропускается |
| `audio/music/` | Фоновая музыка (`theme.mp3`). Нет файла — играет встроенная мелодия |
| `audio/sfx/` | Свои звуки вместо встроенных (см. ниже) |
| `audio/voice/` | Озвучка фраз для «Повтори фразу» |

Форматы: картинки — PNG, JPG, WEBP, SVG, GIF; видео — MP4 (H.264) или WEBM; звук — MP3, OGG, WAV, M4A.
Если картинки нет, вместо неё рисуется аккуратная заглушка, игра не ломается.

## Видео

Положите файлы в `videos/` с такими именами (или впишите свои имена в редакторе):

- `intro.mp4` — вступление перед картой;
- `victory.mp4` — перед финальным подиумом;
- `location_hut.mp4`, `location_forest.mp4`, `location_donkey.mp4`, `location_duloc.mp4`, `location_cat.mp4`, `location_dragon.mp4`, `location_castle.mp4`, `location_throne.mp4`, `location_swamp.mp4` — заставки локаций.

Любой ролик пропускается кликом или пробелом. Выключить все заставки локаций: `game.json → "locationVideos": false`.

## Звуки

Файл `audio/sfx/<имя>.mp3` (или `.ogg`, `.wav`, `.m4a`) заменяет встроенный звук. Имена:
`click`, `hover`, `open`, `correct`, `wrong`, `tick`, `timeUp`, `fanfare`, `reveal`, `add`, `remove`, `dice`, `land`, `hop`.

## config/game.json — общие настройки

| Поле | Что значит |
|---|---|
| `title`, `subtitle` | Название на заставке |
| `perfectBonus` | Бонус луковиц за прохождение без ошибок (по умолчанию 50) |
| `introVideo`, `victoryVideo` | Имена роликов из `videos/` (`""` — не показывать) |
| `locationVideos` | `true`/`false` — показывать заставки локаций |
| `music` | Файл из `audio/music/` (`""` — встроенная мелодия) |
| `musicVolume`, `sfxVolume` | Громкость от `0` до `1` |
| `mapBackground` | Фон карты из `images/map/` |
| `particles` | Светлячки на фоне. На слабом ноутбуке можно выключить: `false` |
| `quickCount`, `trueFalseCount`, `finalCount` | Сколько вопросов в «Быстрых вопросах», «Правде или лжи», «Финальном квизе» |

## config/teams.json — команды

```json
{ "id": "shrek", "name": "Команда Шрека", "color": "#4CAF50", "emoji": "🧅", "character": "shrek.svg" }
```
От 2 до 6 команд. `character` — картинка из `images/characters/`. Названия и цвета можно поменять и прямо перед игрой, на экране «Кто отправляется в путь?».

## config/locations.json — локации

```json
{ "id": "forest", "name": "Лес", "icon": "forest.svg", "x": 11, "y": 46, "game": "quick_questions",
  "reward": 200, "time": 30, "video": "location_forest.mp4", "description": "5 вопросов с вариантами ответа." }
```
- `x`, `y` — где на карте центр локации, в процентах от ширины и высоты;
- `game` — какая мини-игра: `guess_description`, `quick_questions`, `repeat_phrase`, `odd_one_out`, `charades`, `true_false`, `word_builder`, `shout`, `final_quiz`;
- `reward` — луковицы за задание;
- `time` — секунды. Для `shout` это время крика одной команды, для `final_quiz` — время на один вопрос.

## config/questions.json — вопросы и задания

Для каждой мини-игры свой список. Во время партии вопросы не повторяются, пока не кончится список.

```jsonc
"guess_description": [{ "text": "Он живёт на болоте…", "answer": "Шрек" }],
"quick_questions":   [{ "q": "Как зовут лучшего друга Шрека?", "options": ["Осёл", "Кот", "Пряня", "Дракон"], "correct": 0 }],
"repeat_phrase":     [{ "phrase": "Это моё болото!", "character": "Шрек", "mood": "angry", "audio": "" }],
"odd_one_out":       [{ "title": "Кто здесь не животное?", "items": [{ "image": "donkey.svg", "label": "Осёл" }, …], "odd": 2, "explanation": "Пряня — печенье!" }],
"charades":          [{ "character": "Шрек", "hint": "Покажите огра, который рычит" }],
"true_false":        [{ "statement": "Шрек живёт в замке.", "answer": false, "explanation": "Шрек живёт на болоте." }],
"word_builder":      [{ "word": "ШРЕК", "hint": "Главный огр" }],
"shout":             [{ "phrase": "ЭТО МОЁ БОЛОТО!" }],
"final_quiz":        [{ "q": "Как зовут принцессу, которую спас Шрек?", "answer": "Фиона" }]
```

- `correct` и `odd` считаются **с нуля**: первый вариант — `0`, второй — `1` и так далее;
- `mood` — интонация: `angry` 😡, `happy` 😂, `scared` 😱, `sad` 😢, `romantic` 😍, `proud` 😎;
- `audio` — файл из `audio/voice/` с примером. Пусто — пример читает синтез речи Windows;
- `word` — до 16 букв;
- в `odd_one_out` ровно 5 картинок из `images/characters/`.

## Если что-то сломалось

- Ошибка в JSON (лишняя запятая, кавычка) не роняет игру: вверху появится жёлтая плашка «⚠ questions.json: ошибка в строке 12 — использую стандартный», а игра возьмёт встроенные вопросы. Исправьте строку и перезапустите.
- Вернуть всё как было: удалите файл из `config/` — при следующем запуске игра использует встроенный. Или возьмите резервную копию `*.bak.json` и переименуйте её обратно.
- Удалите всю папку `assets/` — при запуске игра создаст её заново со стандартным контентом.
- Лог: `%APPDATA%\shrek-path\logs\main.log`.
