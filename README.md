# Путь Шрека

Настольная игра-бродилка для проектора: команды бросают кубик, идут по карте из 9 локаций вокруг болота Шрека и проходят мини-игры за луковицы 🧅.

## Как запустить (Windows 10/11)

1. Распакуйте архив `Путь-Шрека-1.0.0.zip` в любую папку.
2. Запустите `Шрек-Игра-1.0.0-portable.exe`. Установка не нужна, первый запуск занимает несколько секунд.
3. Игра открывается на весь экран. `F11` — окно/полный экран, `M` — звук, `Пробел` — бросить кубик, `Esc` — меню.

Папка `assets/` рядом с exe — это весь контент игры: вопросы, картинки, видео, музыка. Как её менять — в `assets/README_EDIT.md`. Если запустить exe без этой папки, игра создаст её сама со стандартным контентом.

Если Windows показывает «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае» (у exe нет платной цифровой подписи).

## Как играть

- Ведущий нажимает «Начать игру», задаёт названия и цвета команд → «В путь!».
- Ходит активная команда: кубик → фишка прыгает только по **ещё не пройденным** локациям → заставка → мини-игра → очки.
- Когда пройдены все 9 локаций — финальный подиум.
- Партия сохраняется на каждом ходу: если окно закрыли, в меню появится «⟲ Продолжить».
- «Кричи громче» использует микрофон ноутбука. Если микрофона нет, ведущий выбирает победителя сам.

## Для разработчика

```bash
npm ci
npm run dev             # Vite + Electron с горячей перезагрузкой
npm run check           # typecheck + проверка assets/
npm run test:e2e        # полный проход партии в Electron (на Linux без экрана: xvfb-run -a npm run test:e2e)
npm run build:portable  # release/Путь-Шрека/ (exe + assets + README) и zip
node scripts/build-portable.mjs --linux   # распакованная Linux-сборка для проверки
node scripts/gen-art.mjs                  # перегенерировать SVG-картинки в assets/images
npm run icon                              # build/icon.svg → icon.png + icon.ico
```

Переменные окружения для отладки: `SHREK_ASSETS` — другая папка assets, `SHREK_USER_DATA` — другая папка сохранений, `SHREK_WINDOWED=1` — запуск в окне.

Архитектура и принятые решения — в `PLAN.md`.
